### 首页文字过暗的根本原因

1. `assets/smori.css` 的调色板是"反转"的：`--white: #000000`、`--black: #000000`、`--cream: #111111`。
   Hero 区块的 `.hero-content { color: var(--white) }` 实际是黑字压在黑色背景上，标题、描述、按钮几乎不可见。
2. 区块的 HTML class 与 CSS 不匹配（例如模板用 `.hero-tagline / .hero-heading / .hero-description / .btn-primary / .btn-secondary / .nav-logo / .brand-quote`，CSS 里只有 `.hero-tag / .hero-desc / .btn-gold / .btn-ghost / .logo / .brand-inner blockquote`），所以这些元素没有任何样式，只能继承默认色。
3. 滚动后导航栏切换为白底（旧的浅色主题规则），但链接颜色仍是 #d0d0d0 浅灰，白底浅灰同样看不清。
4. `smori-gallery.liquid` 有一处 `{% if %}` 分支内开标签、分支外闭标签的写法，Theme Check 报语法错误（Shopify 能容错渲染，但已修正）。

## 三、未改动 / 需要注意
- 首页依然是 `.liquid` 模板，区块顺序在主题编辑器里不能拖动，只能改各区块设置（与原来一致）。
- Liquid 一次最多遍历 50 条元对象；案例超过 50 条后需要改为分页或博客方案，届时再处理。
- Theme Check 对 Dawn 自带的 50 多个语言文件会报大量 "MatchingTranslations"（原主题就有，新增的 `smori.*` 文案也只补了 en / zh-CN / zh-TW），不影响运行，缺失语言自动回退到英文。
- `smori-craftsmanship.liquid` 的 `<img>` 缺少 width/height 属性（原有问题，仅影响 Lighthouse 评分）。
- 照片 AI 助手、自动发布、AI 客服 **没有** 放进主题；接入方案见 `04-AI后端接入方案.md`。主题内没有任何 API 密钥。
