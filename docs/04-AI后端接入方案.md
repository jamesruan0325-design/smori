# AI 功能后端接入方案

覆盖三项需求：① 照片助手（上传安装照片 → 分类建议 + 中英文案例介绍 + 小红书标题正文 → 审核 → 发布）；② 自动发布；③ 网站 AI 咨询助手（中英文产品咨询、客户传图、收集预约测量）。

三条原则（按您的要求）：
1. **主题里不放任何 API 密钥。** Claude API Key、Shopify Admin API Token 只存在后端服务的环境变量 / 密钥管理里。
2. **不用固定回复冒充 AI。** 主题里不会内置"假聊天"。聊天组件只有在后端服务上线并在主题设置里填好接口地址后才显示，否则完全隐藏。
3. **AI 只负责生成，人负责发布。** 所有 AI 产出先落为"草稿"，经人工审核后才对外可见。

## 一、整体架构

```
Shopify 后台                           后端服务（一个小型 Node/TypeScript 应用）             Claude API
─────────────                        ─────────────────────────────────────────           ──────────
内容 > 元对象 installation_case  ◄──┐  ┌─ /admin  照片助手页面（内部使用，需登录）          claude-opus-5
  草稿 ─审核─► 已发布               │  │    上传照片 → 调用 Claude 视觉 + 结构化输出          （视觉 + 结构化输出）
                                    └──┤    → 写入元对象（DRAFT）+ 上传照片到 Shopify Files
网店主题（本次已做好）                  │
  smori-cases 区块读取已发布案例         ├─ /proxy/chat   AI 咨询助手接口（通过 Shopify App Proxy）
  详情页 metaobject 模板                 │    验证 Shopify 签名 → 调 Claude → 流式返回
                                        ├─ /proxy/upload 客户照片上传（预签名 URL → 对象存储）
                                        └─ /proxy/lead   预约测量表单 → 数据库 + 邮件/微信通知
```

**后端形态：一个 Shopify 自定义应用（Custom App）+ 一个 Web 服务。**
- 自定义应用只需在 S. MORI 店铺后台创建（设置 → 应用和销售渠道 → 开发应用），不用上架应用商店。
- 需要的 Admin API 权限：`read_metaobjects` `write_metaobjects` `write_files` `read_products` `read_customers` `write_customers`（预约线索建客户时用）。
- App Proxy：把 `smoriwindowfashion.com/apps/assistant/*` 转发到后端，浏览器请求不直接暴露后端地址，Shopify 会附带 HMAC 签名，后端验证后才处理。
- 部署建议：Cloudflare Workers / Vercel / Fly.io 任一，配对象存储（Cloudflare R2 或 AWS S3）存客户上传的照片，数据库用 Postgres（Neon / Supabase）或 SQLite（Turso）。

## 二、照片助手（功能 2）

### 流程
1. 员工登录后端 `/admin`（Shopify 员工账号 OAuth 或简单的邮箱 + 密码 + 2FA）。
2. 上传 1–10 张安装照片，可选填：产品名、地点、备注。
3. 后端调用 Claude，一次请求同时传入全部照片 + 产品目录（8 个系列的名称和特点，从主题的产品文案整理）+ 输出格式要求，使用 **结构化输出** 直接拿到 JSON：

```json
{
  "category": "sheer",                        // 从 7 个分类里选
  "category_confidence": 0.86,
  "category_reason": "S 形叶片悬浮在两层薄纱之间，符合 Silhouette 特征",
  "product_name": "Silhouette",
  "room": "Living Room", "room_zh": "客厅",
  "title": "...", "title_zh": "...",
  "subtitle": "...", "subtitle_zh": "...",
  "summary": "...", "summary_zh": "...",
  "description_html": "...", "description_zh_html": "...",
  "xhs_title": "...",                          // ≤ 20 字，带 1 个 emoji
  "xhs_body": "...",                           // 含话题标签，如 #窗帘 #尔湾
  "photo_order": [2, 0, 1],                    // 建议的封面和排序
  "warnings": ["第 3 张照片有人脸，建议打码"]
}
```
   - 模型：`claude-opus-5`（默认，视觉识别和中英文文案质量最好）；每条案例约 10 张图 + 2K 字输出，成本约 0.1–0.2 美元。
   - 请求示例（TypeScript，官方 SDK）：图片以 `{ type: "image", source: { type: "base64", media_type, data } }` 内容块传入，输出用 `output_config.format`（`zodOutputFormat(schema)`）约束为上面的 JSON，`client.messages.parse()` 直接得到已校验的对象。
   - 系统提示里固定放：品牌语气（高端、克制、不夸张）、产品知识、分类定义、小红书写法要求（标题 ≤ 20 字、正文 200–400 字、结尾话题标签）、"不确定时降低 confidence 并说明"。
4. 页面展示 AI 结果，员工可逐字段修改，然后点 **保存为草稿**：
   - 照片通过 Admin GraphQL `stagedUploadsCreate` + `fileCreate` 上传到 Shopify Files；
   - `metaobjectCreate`（type `installation_case`，字段 key 与主题一致，`capabilities.publishable.status = DRAFT`）写入案例，`xhs_title` / `xhs_body` 一并存入。
5. 审核人在 Shopify 后台"内容 → 元对象"里最终检查，改为 **已发布**；网站自动出现，无需改主题。

### 自动发布（"审核后发布"）
- **网站**：发布 = 把元对象状态从 DRAFT 改为 ACTIVE，可以在 Shopify 后台点，也可以在 `/admin` 页面点"批准并发布"（后端调 `metaobjectUpdate`）。
- **小红书**：小红书没有对外开放的发布 API（企业号的 API 仅限合作方）。方案：
  1. 默认：`/admin` 页面提供"复制标题 / 复制正文 / 下载已排序的照片包"，运营在小红书 App 里粘贴发布（1 分钟以内）；
  2. 若之后拿到小红书企业号开放平台资质，再加一个发布适配器，不影响前面的流程。
- 可选加一个"待审核"提醒：新草稿创建后发邮件 / 企业微信通知审核人。

## 三、网站 AI 咨询助手（功能 3）

### 前端（主题侧，下一阶段再加进主题）
- 一个右下角悬浮聊天组件 `sections/smori-assistant.liquid` + `assets/smori-assistant.js`。
- 主题设置里只有：**启用开关、App Proxy 路径（默认 `/apps/assistant`）、欢迎语（中英）**。没有密钥。
- 开关关闭或接口 404 / 未配置时，组件不渲染。接口出错时显示"暂时无法连接，请拨打 (949) 880-1322 或留下联系方式"，不会伪造回答。

### 后端 `/proxy/chat`
- 验证 Shopify App Proxy 签名；按访客 IP + 会话做限流（例如每分钟 10 条、每天 60 条）防止被刷。
- 调用 Claude（`claude-opus-5`，流式返回，`thinking: { type: "adaptive" }`），系统提示包含：
  - 品牌信息、8 个产品系列的特点与适用场景、服务范围（南加州、上门测量、电动/智能家居、商业项目）、营业时间与联系方式；
  - 语言规则：跟随客户语言（中文 / 英文）；
  - 边界：不报具体价格（引导预约测量）、不承诺交期、不回答与窗饰无关的问题；
  - 工具：`create_measurement_request`（收集姓名、电话/邮箱、地址或城市、窗户数量、意向产品、期望时间）和 `get_product_info`（从后端产品表取资料，避免编造）。
- 客户上传照片：前端先请求 `/proxy/upload` 拿预签名 URL 直传对象存储，然后把图片 URL 放进对话；后端把图片作为 `image` 内容块交给 Claude 分析（窗型、朝向、现有窗饰、推荐系列）。照片保留 30 天后自动删除，隐私说明写在聊天窗口里。
- 预约信息：模型调用 `create_measurement_request` 后，后端写数据库、给 BonnieX@smoriwindowfashion.com 发邮件（Resend / SendGrid），并可选在 Shopify 建客户记录（`customerCreate`，打 tag `measurement-request`）。聊天里同时提供普通表单作为兜底。
- 对话记录保存在后端（供复盘和改进提示词），不存 Shopify。

### 成本与运行
- 每次对话 5–10 轮，约 0.02–0.05 美元；月均 1000 次对话约 30–50 美元。
- 若要压低成本，可将聊天改用 `claude-sonnet-5`（照片助手保持 opus）。

## 四、安全与合规要点
- 所有密钥在部署平台的环境变量 / Secrets 中；代码仓库和主题里不出现。
- App Proxy 签名校验 + 限流 + 输入长度限制；上传只接受 jpg/png/heic，单张 ≤ 10 MB。
- Admin API Token 只在后端使用；前端永远只经过 App Proxy。
- 客户照片和联系方式：说明用途、保留期限、删除方式（隐私政策页补充一段）。
- Claude API 默认 30 天数据保留，不用于训练。
