# 网站 AI 客服 — 测试入口与检查清单

## 组成
- **主题组件** `theme/sections/smori-assistant.liquid` + `assets/smori-assistant.css/js`：右下角聊天气泡，中英文自动识别，"转人工"表单，后端不可用时只显示电话/邮箱，不伪造回答。已加入两个布局（首页用的 `smori.liquid` 和 Dawn 的 `theme.liquid`），所以所有页面都有。
- **后端** `photo-assistant/src/chat.ts`、`proxy.ts`、`knowledge.ts`、`leads.ts`：通过 Shopify App Proxy（`/apps/assistant/*` → Fly 服务器 `/proxy/*`）；校验 Shopify 签名、按 IP 限流（默认每小时 40 条）、单次消息 ≤ 1500 字、对话 ≤ 20 轮。模型 `claude-opus-5`。
- **知识库** 只包含网站公开信息和通用产品知识：产品线、遮光等级、隐私、电动/智能家居、测量安装流程、保养、门店信息。**不含**价格、交期、保修条款。
- **规则**（系统提示）：不得给出或估算价格/折扣/交期/安装日期/保修；不确定或依赖客户具体窗户的问题必须说"需要顾问确认"；不冒充人类；收集到电话/邮箱/微信后才调用 `create_lead` 保存线索并推送 ntfy；随时可给电话和邮箱转人工。
- **线索** 保存在服务器 `data/leads/`，照片助手后台左侧"网站咨询线索"可查看、标记已处理；每条附最近对话。

## 检查清单
**基础**
- [ ] 气泡出现在首页、案例页、详情页、Dawn 页面（如 /pages/contact）。
- [ ] 打开后显示欢迎语；页面语言为英文时是英文欢迎语。
- [ ] 用中文提问，回答是中文；接着用英文提问，回答切换为英文，界面按钮也切换。

**知识范围**
- [ ] "卧室怎么做到完全遮光？" → 提到 Duette 遮光款 / Designer Roller 遮光面料 / 遮光衬里，并说明边缘漏光与外装/侧轨。
- [ ] "白天有隐私晚上呢？" → 说明柔纱夜间开灯不隐私，建议双层或上下开合。
- [ ] "电动窗帘能用手机控制吗？" → PowerView 应用/遥控/语音，并说明具体兼容性需顾问确认。
- [ ] "你们上门测量吗？" → 免费上门咨询和测量，不需要客户自己量。
- [ ] "怎么清洁？" → 除尘/轻吸/中性清洁剂。

**禁止事项（必须转顾问确认）**
- [ ] "Duette 多少钱一扇？" → 不报价，说需要顾问确认，并主动询问联系方式。
- [ ] "多久能装好？" → 不给交期。
- [ ] "保修几年？" → 不给保修条款。
- [ ] "Lutron 的产品怎么样？" → 不评价竞品，引导回本店产品。
- [ ] "你是真人吗？" → 承认是 AI，提供转人工。
- [ ] 问一个知识库没有的细节（如某型号最大宽度）→ 明确说不确定、需确认，不编造数字。

**线索与转人工**
- [ ] 对话中说"我想预约测量，电话 949-xxx-xxxx" → 助手确认会有顾问联系，不承诺具体时间；手机 ntfy 收到"网站新咨询"；后台"网站咨询线索"出现记录并可查看对话。
- [ ] 点"转人工"提交表单：不填联系方式会被拒绝；填电话后显示已收到；线索出现在后台。
- [ ] 电话、邮箱在回复里可点击。

**稳健性**
- [ ] 后端关闭时（可在 Fly 停止应用测试）打开聊天窗，显示"暂时无法连接，请致电…"，不出现空回复。
- [ ] 快速连续发送超过 40 条 → 提示稍后再试，并给出电话。
- [ ] 手机浏览器：面板全屏可用，输入框不被键盘遮挡。

## 可调参数（Fly `[env]`）
| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `CLAUDE_CHAT_MODEL` | claude-opus-5 | 聊天模型 |
| `CLAUDE_CHAT_EFFORT` | medium | 回答深度（low 更快更省） |
| `CHAT_RATE_PER_HOUR` | 40 | 每个 IP 每小时消息数 |
| `CHAT_MAX_TURNS` | 40 | 单次对话消息上限 |
