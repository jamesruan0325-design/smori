# 预览测试步骤（不发布到线上）

ZIP 文件：`smori-theme-installation-cases-2026-09-17.zip`

## 1. 上传为未发布主题
1. Shopify 后台 → **网店 → 主题**。
2. 在"主题库"中点 **添加主题 → 上传 ZIP 文件**，选择上面的 ZIP。
3. 上传完成后主题出现在"主题库"里，**不要点"发布"**。线上主题不受影响。
4. 建议把主题重命名为 `SMORI – 安装案例 2026-09-17`，方便区分。

## 2. 后台配置（第一次）
按 `02-Shopify后台配置-安装案例.md` 完成：
- 创建元对象定义 `installation_case`（含 Publishable + Web pages）；
- 添加 2–3 条测试案例（其中至少 1 条"已发布"、1 条"草稿"）；
- 创建页面 `installations`，模板选 `installation-cases`。

元对象定义是店铺级别的，创建后不会影响线上主题（线上主题不读取它）。

## 3. 预览与检查清单
在主题库里对新主题点 **自定义** 进入编辑器，或点 **… → 预览**。

**首页**
- [ ] Hero 大标题为白色，"Timeless Elegance" 为金色斜体，描述文字可读，两个按钮清晰（金底黑字 / 白边白字）。
- [ ] 顶部导航显示 SMORI、Collections、Installations、Book Consultation；向下滚动后导航变为深色半透明，文字仍清晰。
- [ ] "Our Philosophy" 引言为大号衬线斜体。
- [ ] 产品系列 8 张卡片和文案与线上一致，筛选按钮正常。
- [ ] 新的 "Recent Installations" 区块显示已发布的案例（草稿不显示），分类筛选可用，"View All Projects" 跳到案例页。
- [ ] 联系表单可以提交（提交后显示成功提示）。

**案例页 `/pages/installations`**
- [ ] 显示全部已发布案例，按分类筛选正常。
- [ ] 点击卡片进入详情页。

**案例详情页**
- [ ] 封面 + 照片墙，点击照片可放大，左右切换，Esc 关闭。
- [ ] 项目信息卡内容正确，"Book a Free Measurement" 滚动到页面下方表单。
- [ ] 同类案例推荐（需要至少 2 条同分类案例）。

**中文**
- [ ] 在预览地址后加 `/zh-cn`（需已添加中文语言）或在编辑器右上角切换语言：标题、简介、介绍显示中文字段，界面文案为中文。

**手机**
- [ ] 编辑器切换到手机视图：Hero、卡片单列、照片墙单列、灯箱可用；汉堡菜单可打开。

**主题编辑器**
- [ ] 首页 Installation Cases 区块的各项设置可改；把所有案例设为草稿后，编辑器里显示"还没有安装案例"提示，而前台不显示任何内容。

## 4. 通过后再上线
确认没问题后，在主题库里对该主题点 **发布**。发布前建议先"复制"线上主题做备份（Shopify 会自动保留之前的主题在主题库里，可随时切回）。

## 5. 回滚
任何时候在主题库里对旧主题点"发布"即可回到原版；元对象数据不受主题切换影响。
